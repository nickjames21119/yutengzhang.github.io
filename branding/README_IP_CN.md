# YZ monogram / 品牌视觉资产与知识产权准备（v6）

## 标识设计
主标识使用 **Yuteng Zhang** 的首字母 **Y 与 Z** 作为一体化的路径单线构造：Y 的右上分支与 Z 的上横共享接点，Y 的下垂主干对应出行路径，Z 的斜向转折表达跨学科研究中的连接和变化。暗色网站使用暖金色；浅色模式通过 CSS 继承主题色。

## 文件与图形一致性
- `YZ-primary-gold.svg`：透明背景金色版（主母版）
- `YZ-black.svg`：透明背景纯黑版，适合相似性检索或正式提交前制作规范图
- `YZ-white.svg`：透明背景纯白版
- `YZ-favicon.svg`：小尺寸浏览器图标，带黑色底面
- 所有文件共享同一 YZ 线性几何，但浏览器图标单独带背景。`public/assets/brand-yz.svg` 是网站导航标识唯一源文件。

## 申请前须知
该设计为项目中的原创创作方案（未做相似商标、图形或现有设计的完整检索），**不能保证新颖性、独创性、可注册性或可授予专利**。

作为个人品牌 Logo，通常先评估 **商标注册** 与（视适用法域和具体创作权属）著作权保护；**外观设计专利**不是对抽象标志本身的通用保护，通常要求标志具体应用于符合规定的产品或图形用户界面等保护客体。美国 USPTO 提示纯装饰图案不附着于制造物件通常不能单独作为外观设计专利主题。

正式提交之前应：检索中国商标局/国家知识产权局与 USPTO 相关数据库；明确申请人及创作/协作权属；让代理人根据中国、美国或其他目标地区法规确定保护形式及提交视图，并考虑公开披露对新颖性要求的影响。不要直接将此 SVG 当作专利法定图纸提交。
