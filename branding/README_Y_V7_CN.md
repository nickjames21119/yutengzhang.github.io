# v7：Y 节点标识 / Visual Identity

### 几何比例

* 原型来自最早的 **Y + 三端点**，不采用 v6 的 YZ 连字。
* 母版视口为 64 × 64，标志左右端点圆心 x=15.2 / 48.8（圆心水平跨度 33.6），上端 y=15.0，下端 y=50.6（圆心垂直跨度 35.6），故主视觉宽高比例约 **0.94:1**。整体形态接近垂直略长的经典字母 Y，留白均衡。
* 分叉交点 (32, 32.1)、三端点圆心 (15.2,15)、(48.8,15)、(32,50.6)，四个节点对齐三条几何路径。主线统一宽 3.35，末端节点半径 3.25，交点节点半径 2.1。
* 使用圆角连接、低饱和香槟金色、透明背景；图形不增加环形外框或额外字母。

### 文件

* 运行主页使用 `public/assets/brand-y.svg`（CSS 可根据主题自动着色），构建脚本会把它内联到网站导航栏。
* `public/assets/favicon.svg` / `branding/Y-favicon.svg`：深色底的浏览器图标。
* `branding/Y-primary-gold.svg`、`Y-black.svg`、`Y-white.svg`：不同配色的矢量母版。
* `branding/YZ-*.svg` 为 v6 历史版本，仅供比对，不是当前 Logo。
